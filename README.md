# 德州扑克 v1.5.1

Electron 桌面德州扑克游戏，支持标准德州、短牌 6+、本地 AI 对局和本地 WebSocket 联机房间。

## v1.5.1 重点变化（架构与正确性修复）

- **服务端不再被单个异常击穿**：AI 的对手画像钩子、WebSocket 消息处理、Electron 主进程都加了异常边界。此前 AI 记账抛出一个异常会沿 `ws.on('message')` 逃逸，而服务端与界面同进程，整个应用会退出。
- **AI 胜率采样不会再挂死**：当一个"已弃牌"的对手仍在采样集合中时，组合表为空会让采样循环失去进度且墙钟刹车永不触发；现在会跳过无效座位并在连续无进展时退出。
- **联网短牌 AI 的手牌评估修正**：服务端此前回落到标准牌型评估器，短牌下同花/葫芦次序与 A-6-7-8-9 轮子都是错的，同一手牌联网与单机决策不一致；现在统一走与浏览器相同的位计数评估器。
- **服务端 AI 提速一个数量级**：AI 采样改用与胜率分析一致的评估器（每手 27µs → 0.8µs），10 人桌河牌单次决策从 47ms 降到 3.4ms，事件循环不再被长时间独占。
- **本地与联网 AI 决策可复现（与 v1.5.0 同分布）**：墙钟只在真正超预算时（预算的 3 倍）中断采样，采样预算因此与实际机器负载无关，同一决策在不同负载下结果一致。**注意：不要为了"样本数不影响混合"而把采样与混合掷骰拆成两条随机流** —— 实测这样会改变每个决策的随机序列，固定座位配对测试中 12 组种子前缀全部弱于单流（-25k ~ -229k 筹码/120 手）。随机流保持单条，决策分布与 v1.5.0 逐点一致。
- **标准与短牌共用一套下注引擎**：新增 `js/engine.js`，两个玩法原先复制粘贴的下注状态机（同名方法 29 个、其中 5 个逐字相同、真实差异仅 2 处）现在只有一份实现；规则修复不再需要改两遍。
- **AI Worker 有超时兜底**：Worker 卡死不再让整局停在等待决策，超时会退回主线程计算。
- **房间与联机语义修正**：从未开局的空房间立即释放槽位（此前要占满 60 秒，连续建房会被误报"房间已满"）；客户端不再对限流（1008）与顶号（4001）等终止码自动重连；服务端校验协议版本，名字长度有上限。
- **界面渲染大幅减负**：座位节点跨帧复用、去掉清空容器后立刻读尺寸的强制同步布局、房间配置未变化时不再重建设置控件。联机每条状态消息的元素创建数从 34 降到 1。
- **可用性修复**：在输入框里打字不再触发弃牌/跟注/加注/全下快捷键；`window.game` 改为实时取值，不再指向已替换的旧实例；金额显示统一走同一个格式化函数。
- 测试从 36 个增至 **72 个**，并新增 `tests/regression.test.js` 把这轮修复逐条钉住；`npm test` 带 30 秒用例超时（回归会变红而不是挂死）。

## v1.5.0 重点变化

- 本地与联网 AI 使用同一套范围、风险收益、对手画像、反向博弈和跨街计划策略；本地决策转入后台线程，不阻塞动画。
- 胜率分析转入后台线程，按真实对手人数计算；转牌和河牌单挑使用精确枚举，并提供更可信的改善牌分类。
- 新增开局手牌从背面翻到正面的动画；手牌可随时点击翻到背面隐藏。公共牌先背面落桌，再逐张翻开。
- 四首牌桌音乐按 1–4 排列，支持顺序播放、单曲循环和随机播放，并使用首曲提前加载、下一曲预载、交叉淡化和轻微牌局阶段强度变化。
- 联网房间使用房主选择的 AI 行动节奏；单人联网桌进入下一手时不再显示等待其他玩家。
- 本地服务端口被其他程序占用时自动选择可用端口；联网客户端支持带退避的断线续连，服务端限制房间、连接、单 IP 和消息频率。
- 规则核心统一了边池、未跟注筹码退还、加注金额语义和决策编号；新一手开始会完整清空上局公共牌与结算状态。

## 本地运行

```bash
npm ci
npm test
```

桌面安装版启动时会自动在 `127.0.0.1:3000` 启动联机服务。

## 独立启动联机服务

```bash
npm ci
npm run server
```

服务端入口为 `server/local-server.js`，默认只监听 `127.0.0.1:3000`。如果部署到其他服务器，请按实际网络环境配置监听地址、防火墙和反向代理，并在客户端联网页面修改 WebSocket 地址。

面向少量朋友联机的默认保护为最多 3 个房间、24 个连接、单 IP 20 个连接、每连接 10 秒 80 条消息。单 IP 额度覆盖一个 10 人房间，并为同一网络下的重连和多设备留出余量。可按需要设置：

```text
POKER_HOST=0.0.0.0
POKER_PORT=3000
POKER_MAX_ROOMS=3
POKER_MAX_CONNECTIONS=24
POKER_MAX_CONNECTIONS_PER_IP=20
POKER_ALLOWED_ORIGINS=https://你的游戏页面域名
POKER_TRUST_PROXY=1
```

仅在服务位于可信反向代理之后时启用 `POKER_TRUST_PROXY=1`；公网部署推荐使用 HTTPS/WSS，并把页面域名加入 `POKER_ALLOWED_ORIGINS`。

## 测试

```bash
npm test            # 72 个用例（含规则、短牌引擎等价、AI、服务端、UI/网络、回归）
npm run test:ai-smoke   # AI 批量自对局：筹码守恒、动作合法性、卡死检查
npm run test:all        # 两者一起跑
```

测试覆盖标准德州与短牌牌型、概率核心、AI 一致性、边池、全下与加注重开、跨局清理、断线续连、房主迁移、重复请求防重、双客户端同步，以及公网房间上限、消息节流和来源限制。
