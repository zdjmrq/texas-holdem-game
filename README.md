# 德州扑克

一款中文桌面扑克游戏，支持标准德州扑克、短牌（6+ Hold’em）、本地 AI 对局和 WebSocket 联机房间。适合学习牌型、练习下注和与朋友一起玩。

## 开始游戏

Windows 用户可以从 [GitHub Releases](https://github.com/zdjmrq/texas-holdem-game/releases) 查看已发布的安装包。下载版与仓库源码的版本可能不同；使用最新源码的方法见下方。

1. 打开游戏，选择「标准德州」或「短牌」，再选择本地对局或联机。
2. 初次体验建议先玩本地对局，调整人数、初始筹码和盲注等设置，然后开始。
3. 轮到你时，根据牌面选择弃牌、过牌、跟注、加注或全下。只有当前合法的操作才可使用。
4. 摊牌后查看输赢和牌型，再进入下一手。

标准德州使用 52 张牌，从两张手牌和五张公共牌中选出最强的五张组合。短牌只使用 6 到 A，牌型强弱与标准德州有差异；开始前可打开游戏内规则说明。

## 常用功能

- 与 AI 进行本地对局，或在联机房间中与朋友一起玩。
- 胜率分析辅助理解当前牌面；概率是参考，不保证结果。
- 点击自己的手牌可隐藏或显示，隐藏时分析面板也会保护牌面信息。
- 背景音乐支持切歌、音量调节和播放模式选择。
- 顶部提示音开关可控制轮到你行动时的提醒。

## 键盘操作

| 按键 | 功能 |
| --- | --- |
| Tab / Shift+Tab | 向后 / 向前选择控件；主页首次 Tab 优先选中「开始游戏」 |
| Enter / 空格 | 普通状态下激活选中的控件 |
| F | 弃牌 |
| C | 过牌；不能过牌时跟注 |
| R | 打开加注面板，焦点移到金额滑块 |
| A | 全下 |
| ← / → | 加注面板打开时调整金额 |
| Enter / 空格 | 加注面板打开时确认加注；若选中面板内「取消」则取消 |
| Esc | 取消加注 |
| N | 摊牌后进入下一手 |

出牌快捷键只在轮到你且对应操作可用时生效。Tab 选中手牌、按钮或音量滑块后仍可使用 F/C/R/A；在文本框或下拉选择框中输入时保留控件原有行为。加注期间可点击「取消」、用 Tab 选中「取消」后按 Enter/空格，或按 Esc 退出。

## 与朋友联机

桌面应用启动时会自动提供本机联机服务，默认地址为 `ws://127.0.0.1:3000`。进入联机页面后连接服务器，再按照界面提示创建或加入房间，由房主开始游戏。

`127.0.0.1` 仅代表当前电脑。其他电脑需要连接同一台可访问的服务器；默认桌面服务仅监听本机。如需局域网联机，可在服务器电脑上用 PowerShell 独立启动服务：

```powershell
npm ci
$env:POKER_HOST = '0.0.0.0'
npm run server
```

朋友在客户端填写 `ws://服务器的局域网IP:3000`，并确保服务器防火墙允许该端口。公网部署建议使用 HTTPS/WSS 和反向代理。

## 从源码运行

准备 Node.js 和 npm，在项目目录执行：

```bash
npm ci
npm start
```

仅启动联机服务：

```bash
npm run server
```

可用环境变量包括 `POKER_HOST`、`POKER_PORT`、`POKER_MAX_ROOMS`、`POKER_MAX_CONNECTIONS`、`POKER_MAX_CONNECTIONS_PER_IP` 和 `POKER_ALLOWED_ORIGINS`。仅在可信反向代理后启用 `POKER_TRUST_PROXY=1`。

## 开发与测试

```bash
npm test              # 规则、AI、概率、界面和网络回归测试
npm run test:ai-smoke  # AI 自对局检查
npm run test:all       # 运行以上两项
```

界面与游戏逻辑位于 `js/`，样式位于 `css/`，联机服务位于 `server/`，测试位于 `tests/`。AI 策略说明见 [AI_STRATEGY_DESIGN.md](AI_STRATEGY_DESIGN.md)，Android 构建说明见 [RELEASE_ANDROID.md](RELEASE_ANDROID.md)。
