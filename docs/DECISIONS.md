## 已确认（来自交接文档 + 用户 2026-10-23 指示）

1. 用 Rust 从零重写，不保留 Electron/WebView；UI 用 egui 原生绘制。
2. 只重写主版本（Windows x64 桌面版，含标准德州 + 短牌两种模式、本地 AI、联机）；**不做 Android，不做 32 位 Windows**。
3. 原仓库只读，不修改；黄金语料从原 JS 导出。
4. 先正确后性能；AI 验收采用统计等价。
5. ultracode/并行移植在骨架 + 黄金语料完成前不开。
