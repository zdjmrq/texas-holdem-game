# Windows 冒烟测试清单（Phase 6 垂直切片）

> 目的：在用户的 Windows x64 机器上验证 egui 桌面版的功能与系统集成。
> 开发机是 Linux/WSL，Windows 专有行为（IME、托盘、任务栏闪烁、DPI、DX12）只能在这里确认。
> 结果直接填在文末表格，和截图/录屏/日志一起发回即可。

## 0. 准备

### 0.1 构建（一次性，约 5-15 分钟取决于网络）

在仓库根目录打开 PowerShell：

    scripts\\build-windows.cmd

成功后会得到：

    dist/texas-holdem-rs-current/              便携目录，不生成 zip

如果构建失败，先看终端错误和 scripts/README.md 的「常见问题」。

### 0.2 运行

    dist\\texas-holdem-rs-current\\texas-holdem-rs.exe

- 首次运行可能被 SmartScreen 拦截：更多信息 -> 仍要运行（未签名程序的正常现象）。
- 正常双击运行；--scenario 和 --seed 是可重复测试参数，不要用于普通游戏快捷方式。
- 配置/存档位置：%APPDATA%\\texas-holdem-rs\\settings.json（问题反馈时请附带）。

### 0.3 取证方式

- 截图：Win+Shift+S，或应用自带命令行截图模式（见下）。
- 录屏：Win+G（Xbox Game Bar）。
- 日志：debug 构建有 console；release 是 GUI 子系统无控制台，可在 cmd 里重定向：
  poker-app.exe > out.txt 2>&1
- 应用自带截图命令（Linux 上已验证，Windows 上用于取证）：

      poker-app.exe --scenario table-flop --screenshot shot.png --screenshot-frame 70
      poker-app.exe --scenario table-shortdeck --screenshot shortdeck.png --screenshot-frame 70
      poker-app.exe --scenario settlement --screenshot settlement.png --screenshot-frame 70
      poker-app.exe --scenario table --open-raise --screenshot raise.png --screenshot-frame 70
      poker-app.exe --scenario table-flop --hide-cards --screenshot hidden.png --screenshot-frame 70

  --scenario 可选 home / table / table-flop / table-shortdeck / settlement / settings；
  --hide-cards 让手牌默认隐藏（验证分析遮蔽）；--open-raise 进入加注面板截图。
  截图模式会自动退出，可连续跑多个场景收集证据。

## 12. 本轮已知限制（不算失败）

- 联机只做占位页，WebSocket 联机在后续 Phase。
- AI 是临时的确定性策略桩，不是最终 poker-ai（决策质量不作验收）。
- 加注面板的 1/2 快捷键与顶部工具栏悬停行为在 docs/specs/ui.md 完成前按 README 清单实现，
  可能和最终交互有差异。
- 不做 glow 渲染回退（第一版只走 wgpu/DX12；如遇老显卡/远程桌面问题请记录错误信息）。
- 托盘/窗口图标暂用 32x32 PNG，多尺寸 ico 在 Phase 7 补。
- 音乐文件外置在 assets/music，不上 zip 内嵌；如打包缺失需要把 assets 一起带走。
