# v2.0.0 正式版审查

本次审查覆盖全部九个 crate、原生界面、Windows 构建与发布链路。规则/概率、联机、桌面交互分别独立审查并交叉核查，原版仅作只读参考。

## 确认并修复

- 结算入口重复调用会再次按原贡献派彩：结束状态下结算及延迟推进保持幂等。
- 显式重放入口缺少牌数、短牌点数和庄位验证，可能中途 panic：现在在修改状态前原子拒绝。
- 短牌概率输入接受 2–5：明确返回错误。保留历史语料中含 2c 的非法行，并验证拒绝，不删除语料。
- 翻牌持续下注机会及面对持续下注元数据始终为 false：按原版规则记录机会、反加注及每手重置。
- AI 摊牌观察把稳定座位号当向量索引：改按玩家身份定位，覆盖稀疏座位，避免越界或归错人。
- 大厅断线超时依赖旧索引，其他人离房后宽限失效且占满房间：按玩家身份与定时器 token 回收。
- AI 离锁计算期间丢观察事件、旧状态决策被应用、策略 panic 卡桌：排队回放公共证据，校验状态版本，过期后重新调度，异常合法回退；离线强制弃牌也广播公共证据。
- 进入设置无法回原局、设置期间局势仍推进：修复返回与暂停，并让速度修改实际生效。
- 联机旧加注框跨回合、重复点击提交、发送失败锁按钮、跨服务器复用旧凭据：绑定权威回合、发送前预留、失败解锁、隔离服务器状态。
- 隐藏手牌后仍泄漏牌型：同时遮蔽牌型及分析。
- 无音频参数仍打开提示音设备、低内存参数为空实现：统一音频禁用，并限制分析缓存/动画与刷新。
- 小窗口结算位置边界可能触发 clamp panic：保护狭小可用区域。
- 产品版本统一为 2.0.0，增加版本命令；协议兼容标识保留 1.5.8，以便继续与原版协议 v2 互通。
- PowerShell 脚本使用 UTF-8 BOM，兼容 Windows PowerShell 5.1 的中文解码；构建对帮助与版本命令执行限时启动检查，并校验资源和 SHA256。

## 验证

- 标准 2,598,960 与短牌 376,992 个五张组合穷举 hash 对齐，共 2,975,952 个；完整点数直方图、同花掩码与随机评估差分通过。
- 3,200 手混合行动覆盖标准 2–10 人、短牌 2–8 人的牌张唯一性、筹码守恒、动作拒绝和结算不变量。
- 新增结算幂等、非法重放、短牌输入、持续下注、AI 异常与并发、真实 WebSocket 座位回收、界面状态回归；发布前执行全工作区测试、格式检查和严格 Clippy。
- GitHub CI 的 Windows/Ubuntu 检查、黄金语料重建及 JS/Rust 双向互通全部成功后，发布同一提交的 Windows MSVC 原生成品。下载校验包和 exe 的 SHA256，再在本机安装目录启动截图验证。

## 规则与边界

先过牌后面对不足最小下注的全下是否重新开放加注，已复核官方 TDA Rule 49 并保留原版规则，未把规则口径差异当作程序缺陷。

正式版指产品版本及发布渠道，不表示数学上证明程序无缺陷。自动截图与逻辑测试不能替代所有设备上的微软拼音组合输入、多显示器/DPI、人工听音、长时间运行及跨机器网络实测；这些项目仍使用 windows-smoke.md 逐项记录，不将未执行的人工项目标记通过。
